Passagier-Ansagen (PA)

Nutze diese Skripte für realistischen Funkverkehr. Die Daten basieren auf deinem Dispatch.

1. Boarding Welcome

"Meine Damen und Herren, herzlich willkommen an Bord unseres Fluges --- von --- nach ---. Die errechnete Flugzeit beträgt heute ---. Wir schließen in Kürze die Türen."

"Ladies and gentlemen, welcome aboard flight --- from --- to ---. Our flight time today will be ---."

2. Cruise / Reiseflug

"Hier spricht Ihr Kapitän. Wir haben unsere Reiseflughöhe erreicht. Das Wetter auf dem Weg nach --- ist gut, wir erwarten eine pünktliche Landung. Lehnen Sie sich zurück und genießen Sie den Flug."

"This is your Captain speaking. We have reached our cruising altitude. Weather enroute to --- looks good..."

3. Top of Descent (Anflug)

"Meine Damen und Herren, wir haben soeben den Sinkflug auf --- begonnen. Bitte schnallen Sie sich an und klappen Sie die Tische hoch. Kabinencrew, bitte bereiten Sie die Kabine für die Landung vor."

"Ladies and gentlemen, we have just started our descent into ---. Please fasten your seatbelts..."

Standard Operating Procedures

Realistischer 6-Phasen-Flow (QRH)

1. PRE-FLIGHT

  • Battery 1 & 2 ... ON
  • External Power / APU ... ON
  • ADIRS / IRS ... NAV / ALIGN
  • Fuel & Payload ... CHECKED
  • FMC / MCDU ... ROUTE & PERF SET
  • Altimeter (QNH) ... SET LOCAL
  • Flight Director (F/D) ... ON

2. BEFORE START

  • Doors & Hatches ... CLOSED
  • APU Bleed ... ON
  • External Power ... DISCONNECTED
  • Fuel Pumps ... ON
  • Beacon Light ... ON
  • Parking Brake ... SET
  • Transponder ... TA/RA

3. BEFORE TAKEOFF

  • Flight Controls ... CHECKED
  • Flaps / Slats ... SET FOR T/O
  • Pitch Trim / CG ... SET
  • Autobrake ... RTO / MAX
  • Cabin Crew ... ADVISED
  • Strobes & Landing Lights ... ON

4. DESCENT & APPR

  • Approach Briefing ... COMPLETED
  • FMC Appr Data ... ENTERED
  • Altimeter (Transition) ... SET LOCAL
  • Seatbelt Signs ... ON
  • Autobrake ... SET (LOW/MED)
  • ILS Freq / Course ... CHECKED

5. BEFORE LANDING

  • Landing Gear ... DOWN, 3 GREEN
  • Auto-Spoilers ... ARMED
  • Flaps ... SET FOR LANDING
  • Missed Approach Alt ... SET
  • Landing Lights ... ON

6. PARKING

  • Parking Brake ... SET
  • APU / Ground Power ... ON
  • Engines ... CUTOFF / OFF
  • Seatbelt Signs ... OFF
  • Fuel Pumps ... OFF
  • Exterior Lights ... AS REQUIRED
